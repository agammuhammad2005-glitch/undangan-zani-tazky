### 💡 Cara Mengetes dan Membuka Website:
1. Buka file `index.html` langsung dengan klik dua kali (atau buka lewat browser seperti Chrome / Edge).
2. Untuk melihat tampilan nama tamu khusus, tambahkan parameter `?to=Nama+Tamu` di akhir URL file, contoh:
   - `index.html?to=Bapak+Budi+%26+Keluarga`
   - `index.html?to=Sahabat+Tazky`
